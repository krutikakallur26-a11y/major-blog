# My ML Notebook — Screenshot Version

This is a standalone, single-page Machine Learning blog designed so you can open each topic and capture a separate screenshot for printing.

## Run locally
1. Extract the ZIP.
2. Double-click `index.html` to open it in a browser.
3. The homepage shows all eight topic cards.
4. Click each topic to open the lesson section. Use **All topics** to return home.
5. Press `Ctrl + P` to print the current page or use `Windows + Shift + S` to take a screenshot.

## Included topics
Linear Regression, Logistic Regression, Decision Tree, K-Nearest Neighbour (KNN), K-Means Clustering, Hierarchical Clustering, Principal Component Analysis (PCA), and Association Rule Learning.

Every lesson includes an explanation, workflow, illustrative visualization, dataset/official-resource link, evaluation guidance, Python example, and practical notes. The charts are illustrative and clearly labelled, not real model results from linked datasets.

## Deploy
Upload `index.html`, `style.css`, `script.js`, and `netlify.toml` to the root of your GitHub repository. Netlify can deploy this static site with no build command and `.` as the publish directory.
